1. Quem usa

A ferramenta é usada por um único operador, dono das contas conectadas. Não há cadastro de público, venda de dados nem publicidade.

2. Dados que tratamos

  • Login da ferramenta: o identificador numérico e o nome de usuário do GitHub do operador, só para conferir se o acesso é permitido.
  • Contas conectadas (YouTube, TikTok, Instagram): o identificador e o nome público da conta, e os tokens de acesso concedidos pelo login oficial. Os tokens ficam criptografados no banco de dados.
  • Conteúdo: vídeos e imagens de fontes autorizadas, o texto público do post de origem e o link para ele; os vídeos editados; títulos, descrições e hashtags gerados; e métricas públicas dos vídeos publicados (visualizações, curtidas, comentários).

3. Para que usamos

Exclusivamente para buscar, editar, agendar e publicar vídeos nas contas do próprio operador e acompanhar o desempenho deles. Os dados das plataformas não são compartilhados com terceiros nem usados para outra finalidade.

4. Permissões das plataformas

  • YouTube (Google): enviar vídeos e ler informações do canal (youtube.upload, youtube.readonly). Esta ferramenta usa os Serviços de API do YouTube: valem os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de dados das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de uso limitado. O acesso pode ser revogado em myaccount.google.com/permissions.
  • TikTok: informações básicas do perfil, publicação de vídeos e leitura das métricas dos vídeos publicados (user.info.basic, video.publish, video.list).
  • Instagram (Meta): informações básicas da conta profissional e publicação de Reels (instagram_business_basic, instagram_business_content_publish).

5. Retenção

Arquivos de vídeo são apagados automaticamente pouco depois da publicação (padrão: 30 minutos). Registros de publicação, links e métricas ficam enquanto a operação existir. Tokens ficam até a conta ser desconectada.

6. Segurança

Acesso por login único autorizado, tokens e chaves criptografados, conexões apenas por HTTPS e armazenamento em provedores com controle de acesso.

7. Seus direitos e exclusão

Qualquer conta conectada pode ser desconectada pela própria plataforma ou pela ferramenta, e os dados podem ser apagados conforme a página Exclusão de dados. Titulares podem pedir acesso, correção ou exclusão pelo contato abaixo, nos termos da LGPD.

Privacy policy (English)

This is a private tool used by a single operator, who owns every connected account. It is not offered to the public, does not sell data and shows no advertising.

YouTube API Services

This tool uses YouTube API Services. By using it with a YouTube channel you are bound by the YouTube Terms of Service, and Google's data practices are described in the Google Privacy Policy.

  • Data accessed: the channel ID and name, and the title, ID, link and public statistics (views, likes, comments) of the videos this tool uploads to that channel. Scopes: youtube.upload and youtube.readonly.
  • How it is used: only to upload the operator's videos to the operator's own channel and to show their performance to the operator. Nothing else.
  • Storage: OAuth tokens are encrypted at rest; video files are deleted shortly after publishing; publishing records and statistics are kept while the operation exists.
  • Sharing: YouTube data is not sold, shared, transferred or disclosed to any third party.
  • Revoking access: you can revoke this tool's access at any time in the Google security settings. On revocation the stored token is deleted immediately and stored YouTube data for that channel is deleted within 30 days. See Data deletion.

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Other platforms

For TikTok and Instagram the tool stores only the connected account's public ID and name, encrypted tokens, the videos published and their public metrics, to publish to the operator's own accounts.
